# Codex 제목 답변 누락 방지 검증

2026-09-14. 사용자 요청: Python으로 검증 단계를 추가하고, Antigravity는 수정하지 않는다.

## 변경과 검사 범위

- report_guard.py가 제목 후보와 실사 기록으로 전체 답변을 생성하고 실제 답변 파일과 대조한다.
- 제목 10개·40~60자, 검색 경쟁도 판정표, 수요 근거, 경쟁 문서 분류 수, 답변 빈틈, 판정 한계, 추천 번호와 이유를 포함한다.
- workflow_guard.py의 제목 완료 기록에 보고서 파일이 필수다. 제목 선택 대기의 finish에도 --reply-file이 필수다.
- 보고서 수정 후에는 기존 해시가 일치하지 않아 제목 단계로 복귀한다. 누락/변조 파일은 종료 코드 2로 거절한다.
- WORKFLOW.md에 생성 → 전체 내용 검토 → 완료 기록 → finish → 검증한 전체 파일 그대로 응답하는 순서를 추가했다.

## 검증 결과

`python -B -X utf8 -m unittest discover -s codex_tools -p 'test_*.py' -v`: 20개 테스트 통과.

기존 단계 건너뛰기·선택 누락·근거 변경·제목 길이 경계 검사에 더해 다음 사례를 검증했다.

- 제목만 있는 답변 및 답변 파일을 지정하지 않은 종료 거절.
- 표 전체 삭제, 표 제목만 남기고 근거 행 삭제, 제목 1개 삭제, 중복 제목, 글자 수 변조, 임의 점수 삽입, 추천 이유 삭제, 답변 빈틈 삭제 모두 거절(8개 변조 하위 사례).
- 네이버와 구글의 완전한 답변 통과, 구글 단계에서 네이버 보고서 제출 거절.
- 완료 기록 뒤 보고서를 수정하면 naver_titles로 복귀.

실제 작업 `2026-09-14-추석-고기-선물-수령안전`:

- 이전 `네이버_제목_10개.md`: 필수 항목 누락으로 report_guard check 종료 코드 2.
- 새 `naver_report.md`: check 종료 코드 0. 기존 제목 10개는 유지하고 추천 근거와 필수 판정표를 포함했다.
- 기존 완료 기록은 새 보고서 요건을 만족하지 못해 제목 단계로 복귀한다. 이번 코드 수정 작업에서 사용자 선택을 만들거나 글의 다음 단계로 진행하지 않았다. 다음 제목 제안 시 새 보고서 검토·record·finish가 필요하다.

`data/codex_only_baseline.json`의 Antigravity/공용 파일 7개 모두 SHA-256 일치. 해당 파일을 수정하지 않았다. 이번 변경은 Codex 전용 도구·문서와 해당 글의 Codex 후보 메타데이터/보고서에 한정된다.

## 한계

이 검사는 실행되는 Python 경로와 실제 답변 파일을 검사한다. Codex 앱의 채팅 전송을 직접 가로채는 훅은 아니다. 검증한 파일 전체를 실제 응답으로 사용해야 하며, 근거의 진위와 의미상 판단은 별도 원문 검토가 필요하다.
