# Codex 전용 보완 확인

사용자 지시: 안티그래비티 수정 금지. 제목 길이 40~60자. 중간에 임의 종료하거나 단계를 건너뛰면 누락 단계로 복귀.

이번 변경: codex_tools/workflow_guard.py, WORKFLOW.md, test_workflow_guard.py 및 Codex 전용 글로벌 스킬 진입부 추가.
AGENTS.md, GEMINI.md, BLUE_OCEAN_PROTOCOL.md, tools/step_guard.py, tools/validate_titles.py, tools/add_post.py, skills/naver-honeyjar/SKILL.md 7개는 이번 변경 전후 SHA-256 동일. 앞선 작업의 미커밋 변경은 되돌리거나 덮어쓰지 않았다.

원인 확인: 제목 검색 의도 대조와 중간 질문 후 작업 지속은 AI가 제대로 적용하지 못했다. 공용 step_guard의 2-Track 구글 제목 단계에서 네이버 선택을 검사하지 않는 조건은 git HEAD 원본에도 있었다. 이번에 공용 파일은 수정하지 않고 Codex 전용 순서 검사에서 추가 차단한다.

검증: 13개 오프라인 회귀 테스트 통과. 제목 39/61자 거절, 40/60자 허용(네이버·구글), 선택 누락 구글 진입 거절, 제목 제시 전 종료 거절, 실제 선택 뒤 다음 단계 지속, 오래되거나 변경된 근거 복귀, 검색 질문·제목 대조 불일치 거절, 잘못된 선택·빈 승인 거절 등.
실제 기존 제목 후보 10개도 40자 미만으로 거절됨을 확인했다. 기존 7번 추천은 철회 상태이며 새 규칙의 완료 기록으로 이전 후보를 승격하지 않는다.

현재 글 작업의 복귀 단계는 research. 기존 조사 결과는 보존하고 Codex 전용 공략 질문·사이트 적합성 검토를 마친 후 제목을 40~60자로 다시 제안해야 한다.
Codex 스킬 8,422바이트, 32KiB 미만. 제목 선택·이미지 승인·발행 승인 순서는 보존했다.

한계: 검사기는 호출된 실행 경로에서 오류 코드와 복귀 단계를 반환한다. 응답이 끝난 Codex를 자동 재기동하는 앱 훅이 아니다. 의미 검토·실제 사용자 발언·산출물 진위는 AI가 원문과 대조해야 한다. 완전 강제 또는 재발 0%라고 보고하지 않는다.
