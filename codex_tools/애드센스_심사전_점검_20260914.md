# 꿀단지 애드센스 심사 전 점검 — 2026-09-14

## 판단

기술적 운영 기반은 갖춰져 있다. 하지만 일부 기존 건강 글에 원문과 다른 해석, 안전 안내와 충돌하는 조언, 근거가 불명확한 확정 표현이 있어 승인 가능성이 높다고 단정하기 어렵다. 우선순위는 글 수 확대나 색인 API보다 확인된 콘텐츠 오류 수정이다. 이는 자체 사전 진단이며 Google의 반려 판정이나 승인 확률 예측이 아니다.

## 실제 검사 범위

- 로컬 공개 글 28편의 제목, 본문 출처 링크와 구조를 전체 스캔했다. 글별 모든 의학적 주장을 검증한 것은 아니다.
- 커피·저속노화 밥·공복혈당·과일 세척·눈 감고 누워있기 등 5편은 공개 서버 본문과 로컬 본문 일치를 확인하고 핵심 문제를 검토했다.
- 홈페이지·소개·개인정보처리방침·문의 페이지, ads.txt, 실제 robots.txt를 HTTP 조회했다.
- 실제 브라우저 PC 홈페이지, 모바일 390px 홈페이지와 저속노화 밥 글을 확인했다. 모바일 글의 가로 넘침은 없었고 본문 약 15.68px로 표시됐다.
- 직전 RSS 배포 검증: 공개 주소 41/41 정상, 로컬 HTML 39개·내부 링크 1,035개·에셋 참조 689개 검사 오류 0건. 이 수치는 수집한 모든 외부 참고문헌 검증이나 AdSense 승인을 뜻하지 않는다.
- AdSense 계정의 실제 심사 메시지·정책 센터, Search Console 색인 내역, 유입의 품질, 모든 이미지의 권리 관계는 확인하지 않았다. 사용자가 말한 ‘심사 중’을 전제로 분석했다.
- 사이트 본문·코드·설정은 이번 분석에서 수정하지 않았다.

## 좋은 점

1. 건강·식단·운동이라는 주제 범위와 28편의 공개 콘텐츠가 있다. 이번 분석은 글 수나 글자 수에 임의 합격선을 두지 않는다.
2. 카테고리, 검색 입력, 더보기, 관련 글, 연락처와 정책 페이지가 있다. 카테고리 실제 클릭은 직전 배포 검사에서 검증됐다.
3. 공개 ads.txt의 게시자 ID가 홈페이지 광고 스크립트와 일치한다. 이는 연결 구성 확인이며 계정 승인을 뜻하지 않는다.
4. robots.txt에서 일반 검색과 공개 글을 전면 차단하는 지시는 없고 표본 페이지에 noindex가 없었다. Google-Extended 차단을 검색용 Googlebot 차단으로 해석하지 않았다. 실제 Google 크롤러 접근 로그는 확인하지 않았다.
5. 개인정보처리방침에 Google/제3자 광고 쿠키와 맞춤 광고 해제 링크가 있다.
6. 최근 보완한 고기·비염 글은 구체적인 원문 링크와 조건을 제공해 기존 글보다 근거를 추적하기 쉽다.

## 먼저 수정할 글

### 1. 저속노화 밥 — 안전 안내 우선

URL: https://honeyjar.co.kr/posts/slow-aging-rice-recipe.html

- FAQ는 저항성 전분 보존을 위해 전자레인지에 ‘미지근하게 살짝만’ 데우라고 권한다.
- NHS는 적절히 냉장한 밥을 재가열할 때 전체가 충분히 뜨거워지도록 가열하라고 안내한다. 보관과 재가열 안전을 먼저 설명하고, 저항성 전분을 이유로 불충분한 재가열을 권하지 않도록 고쳐야 한다.
- ‘밥만 바꿔도 노화가 멈춘다’, 혈당 스파이크를 확실하게 잠재운다는 표현은 결과 보장으로 읽힌다. 곡물·식사량·개인차를 설명하는 제목과 본문으로 조정한다.
- 현재 PC 홈과 모바일 에디터 픽에서 크게 노출된다. 픽 지정은 유지하더라도 연결된 글의 안전 안내를 먼저 교정하는 것이 합리적이다.

공인 근거: https://www.nhs.uk/live-well/eat-well/food-types/starchy-foods-and-carbohydrates/ (표시된 검토일 2023-03-15, 2026 자료로 표기하지 않음).

### 2. 식후 커피 — 인용한 논문의 결과와 반대

URL: https://honeyjar.co.kr/posts/coffee-after-meal-golden-time.html

- 참고문헌은 《Inhibition of food iron absorption by coffee》를 ‘식후 1시간 경과 시 흡수율 90% 이상 정상 회복’의 근거로 소개한다.
- 해당 논문 초록은 식사 1시간 **후** 커피를 마셨을 때 식사와 동시에 마신 경우와 같은 정도의 철 흡수 억제를 관찰했다고 설명한다. 이 논문으로 1시간 후 90% 회복을 뒷받침할 수 없다.
- 이 오래된 소규모 연구를 모든 사람의 보편적인 시간 규칙으로 바꾸는 것도 피한다. 연구 대상·비헴철·식사 조건과 개인별 주의 대상을 구분한다.
- ‘점심 영양분을 몽땅 버린다’는 제목도 특정 영양소의 흡수 문제를 식사 전체 영양 손실로 확대한다.

직접 인용된 원문 확인: https://pubmed.ncbi.nlm.nih.gov/6402915/ (1983년 연구. 오래된 자료를 새 근거처럼 채택한 것이 아니라 글이 인용한 논문의 실제 결과를 대조함).

### 3. 공복혈당 — 기간·효과의 혼동과 확정적 개선 표현

URL: https://honeyjar.co.kr/posts/fasting-blood-sugar-prediabetes-guide.html

- 제목의 ‘약 없이 3개월 만에 정상 혈당’, 본문의 숙면 뒤 ‘80~90대로 내려앉는다’는 개인별 결과를 약속하는 방식이다.
- 참고문헌에 ‘DPP 15년 추적 연구: 58% 감소’라고 묶여 있다. NIDDK는 초기 약 3년 결과의 58% 감소와 장기 추적 결과를 구분한다. 연구 기간과 수치를 정확히 연결해야 한다.
- 혈당 재검사·진료와 개인별 생활습관 조정으로 안내하고 치료가 필요 없다는 인상을 줄이지 않도록 한다.

공인 근거: https://www.niddk.nih.gov/about-niddk/research-areas/diabetes/diabetes-prevention-program-dpp

### 4. 과일 세척 — 멍과 부패 구분, 수치·공인 표현 재검증

URL: https://honeyjar.co.kr/posts/fruit-washing-liver-health.html

- FAQ에서 ‘곰팡이가 피었거나 멍든 과일’을 함께 버리라고 한다. 단순 멍과 부패/곰팡이를 구분해야 한다. FDA는 손상·멍 부위를 도려내는 경우와 썩은 과일을 버리는 경우를 구분한다.
- 표의 ‘88~95%’, ‘비타민 100% 완벽 보존’, ‘식약처 공식 평가’와 별점은 실험 조건과 직접 원문을 확인할 수 있게 해야 한다. 이번 점검에서 해당 수치들의 실제 원문을 확인하지 못했으므로 가짜라고 단정하지는 않는다. 확인될 때까지 확정 표현으로 두기 어렵다.
- 앞부분의 ‘물에 담그면 절대 안 되는 과일’과 뒤의 포괄적인 ‘1분 담금’ 지침을 품목별로 정리한다.

공인 근거: https://www.fda.gov/food/buy-store-serve-safe-food/selecting-and-serving-produce-safely

## 사이트 전반 보완

### 출처 추적 가능성

- 28편 중 26편은 검사한 본문 영역에 클릭 가능한 외부 원문 링크가 없다. 기관·자료명이 적힌 참고문헌은 있으므로 ‘출처가 전혀 없다’와는 다르다.
- 핵심 수치와 직접 인용문에는 문서명, 실제 발행/개정 연도, URL/DOI와 해당 조건을 연결한다. 인용 출처의 존재·주장 일치를 먼저 확인하며 관련 없는 기관 홈페이지 링크로 개수를 채우지 않는다.
- 수면 글의 ‘입면 속도 2배’, ‘멜라토닌 50%’와 2026으로 표기된 자료명들도 후속 사실 확인 대상이다. 이번 점검에서는 전부 오류라고 판정하지 않았다.
- 읽은 날짜를 발표 연도로 바꾸지 않는다. 직접 발언을 확인하지 못한 상단 인용 카드는 따옴표 인용 대신 출처의 취지 요약임을 명시한다.

### 운영자·제작 과정 소개

- 소개 페이지는 ‘팩트체크 & 리서치 데스크’, ‘수석 칼럼니스트’, ‘편집국 총괄 감수’ 등을 별도 역할처럼 설명한다.
- 실제 운영 구조와 일치하는지 확인하고, 운영자/필명 관계, AI를 쓰는 부분, 사람이 검토하는 범위를 사실대로 설명하는 것이 좋다. 존재하지 않는 전문가나 의료 감수자를 추가해서는 안 된다.
- E-E-A-T 설명은 검색 품질에 관한 참고 기준이며 AdSense의 별도 자격증·점수·합격 조건으로 취급하지 않는다.

### 개인정보 안내와 실제 처리 일치

- 쿠키와 맞춤 광고 해제 안내는 갖춰져 있다.
- 문의 폼 코드는 FormSubmit로 이름·이메일·문의 내용을 전송하지만 처리방침의 수탁업체 설명에는 Cloudflare만 나온다. FormSubmit 처리와 보관 기간 등 실제 운영을 확인해 안내를 맞출 필요가 있다.
- ‘3개월 자동 파기’, ‘3년 보관’ 같은 문구가 실제 시스템 처리와 일치하는지는 미확인이다. 법 적용·준수 여부를 이번 점검에서 단정하지 않는다. 문의 메일을 시험 발송하지 않았다.

### 낮은 우선순위의 기술 정리

- 공개 홈페이지와 확인한 글에는 같은 AdSense 로더 스크립트가 2회 있다. 템플릿의 중복 삽입을 한 번으로 정리할 수 있다. 이 중복을 승인 거절의 확정 원인이라고 보지는 않는다.
- 관리자/404 원본에는 광고 로더나 수동 광고 슬롯이 없었다.
- 실제 승인 후 광고 배치와 정책 센터의 상태는 별도로 확인해야 한다. 현재 승인 여부와 자동 광고 제외 설정은 계정에서 확인하지 않았다.

## 권장 진행 순서

1. 저속노화 밥과 식후 커피의 확인된 오류를 먼저 고친다.
2. 공복혈당·과일 세척의 수치, 과장과 조건 누락을 정리한다.
3. 나머지 기존 글 24편의 핵심 주장·직접 인용·출처를 순차 검토한다. 이미 최근 검증한 글은 유효한 검토 기록을 재사용한다.
4. 운영 소개와 개인정보 안내를 실제 운영에 맞추고 광고 로더 중복을 정리한다.
5. 원고 수정 시 DB·목록 요약·RSS·네이버 대응 원고까지 같은 사실이 유지되도록 기존 수정 절차를 따른다. URL과 사용자 지정 에디터 픽을 임의 변경하거나 글을 일괄 삭제할 필요는 없다.
