# 본문을 기준으로 조정한 이미지 구성안

구글·네이버 본문 초안 작성 및 텍스트 검사 후 구성했다. 실제 이미지 생성·사용자 이미지 승인은 아직 없다.

| 파일 | 장면 | 구글 배치 |
|---|---|---|
| thumb.jpg | 추석 선물 상자·밀봉 고기·녹은 아이스팩 대표 정물 | 글 상단 대표 |
| post01.jpg | 같은 인물이 배송 알림 시각 확인 | 냉장이 끊긴 시간 설명 |
| post02.jpg | 고기 포장 속 얼음 결정과 식품용 온도계 | 수령 온도 설명 |
| post03.jpg | 같은 인물이 보관 표시·포장 확인 | 냉장·냉동 표시 구분 |
| post04.jpg | 정상 수령한 고기를 별도 밀폐 용기에 구분 보관 | 안전한 보관·재냉동 조건 |
| post05.jpg | 같은 인물이 상자와 제품 상태를 사진으로 기록 | 다음 수령을 준비하는 마무리 |

본문 사진은 인물 3장·정물 2장, 대표 정물 1장은 별도다. 동일한 여성 모델·크림 블라우스·베이지 앞치마·원목과 화이트 주방을 유지한다. 기준 얼굴 이미지를 첫 인물 컷에 실제 참조하고, 이후 컷은 첫 생성 이미지를 참조한다.

네이버도 총 6장을 사용하고, 본문에 맞춰 표시 확인 → 온도 → 시간·보관·기록 순서로 재배치한다. 네이버 사진 아래 설명 캡션은 생략, 구글은 짧은 장면 캡션을 사용하도록 제안한다. 이전 상충 규칙의 장수·캡션 선택은 이번 구성 승인에 포함하며 승인 전 확정하지 않는다.

사진은 AI 연출 이미지다. 실제 배송 사고나 온도 측정 증거로 표현하지 않는다. 온도계·휴대전화 화면에 수치나 글자를 임의 생성하지 않고, 의심스러운 고기를 조리·시식하거나 냉장으로 안전이 회복되는 장면을 넣지 않는다.

본문과 근거는 그대로 보존한다. post04는 이전의 의심 식품 임시 보관 정물에서 정상 수령 후 구분 보관 장면으로 수정해 현재 본문과 맞췄다.


## 가독성 교정 후 대조 · 2026-09-14
사용자 “수정해줘”에 따른 본문 교정. 위 이전 소제목 대신 현재 초안의 소제목과 연결을 재확인했다. 장면·인물·프롬프트·이미지·캡션·배치 순서는 유지한다. 재냉동 절의 보관 사진은 문제가 없는 고기의 분리 보관을 나타내며, 의심되는 고기를 냉장으로 복구한다는 의미가 아니다. 기존 이미지 승인과 이후 휴대전화 사진 교정 요청을 그대로 적용한다.
