## 실행한 검수

- 내장 image_gen으로 6장 생성 후 직접 육안 확인. 원본은 image_originals, 사용본은 images에 보존.
- 이미지 전부 1280×720 JPEG, 172.7~208.3KB, 고유 파일 6개. 압축 목표 용량을 맞추기 위해 JPEG quality는 85~94 범위로 조절했습니다.
- 기존 image_guard 계획 승인·6장 무결성 검사 통과.
- 기존 네이버 44종 금칙어 검사 통과. 사진 경로·5종 아이콘·태그 구조 검사 통과.
- 본문 기준 구글 3,797자, 네이버 공백 포함 1,897자/제외 1,449자. 제목·목차·캡션·참고문헌·FAQ·편집 안내 등은 제외한 기준입니다.
- 본문 15자 이상 동일 문장 0개, 본문 4-gram 겹침 1.12%. 기존 전체 HTML 비교기는 부가 문구를 포함하여 1.82%로 통과했습니다. 검색엔진의 중복 판정 확률을 의미하지 않습니다.
- Codex 단계 검사 → 기존 등록 함수 → 기존 빌드 실행 완료. 실제 생성 파일의 사진 6개·FAQ 3개와 피드·사이트맵·홈·레지스트리 연결 확인.
- 로컬 사이트 HTML 39개, 내부 링크 1,036개, 에셋 689개 검사. 필수 파일·링크·에셋·HTML·파비콘·인코딩 오류 각각 0건.
- 기존 글 27편의 데이터는 최신 글 표시 외 보존. 기존 에디터 픽 보존, 새 글은 false.
- 최신 자료 우선 검색/예외 근거 검사는 앞 단계 기록을 사용했습니다. 기존 공공 지침을 2026년 신규 발표 자료로 표현하지 않았습니다.
