# 꿀단지 공통 꿀벌 스티커

글마다 재사용하는 네 가지 장면용 투명 PNG 원본입니다.

- 01-curious.png: 궁금해요 — 질문과 도입
- 02-check.png: 확인해요 — 핵심 답변과 체크리스트
- 03-investigate.png: 살펴봐요 — 비교와 확인할 기준
- 04-comfort.png: 편안하게 — 실천 안내와 마무리

권장 본문 표시 너비: 120~160px. 가로세로 비율을 유지하고 중앙에 배치합니다. 이미지에 글자가 없어 장면별 문구는 본문에서 작성합니다.

생성 방식: image_gen. 첫 캐릭터 신규 생성 후 동일 원본을 참조하여 나머지 자세를 각각 생성했습니다. 공통 디자인은 둥근 꿀색 얼굴, 갈색 줄무늬와 윤곽선, 옅은 청록 날개, 복숭아색 볼, 투명 배경입니다. 각 자세는 궁금한 표정/체크리스트/돋보기/담요를 덮고 휴식입니다.
