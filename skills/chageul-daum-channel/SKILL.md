# 다음(Daum) 채널 마스터 스킬 (daum-channel)

이 스킬은 다음 채널 글 작성 시 1단계 선행 제목 스킬 발동(daum-title)과 2단계 연쇄 본문 작성(daum-article)을 총괄 통제하는 종합 마스터 컨트롤러입니다.

---

# 2단계 연쇄 발동 마스터 오케스트레이션 수칙

1. [0단계: 리서치 및 폴더 생성]:
   - 주제 데이터 분석 및 실시간 팩트 검증을 거쳐 YYYY-MM-DD-주제명 전용 폴더 및 리서치.md 작성
2. [1단계: 선행 제목 마스터 스킬 발동 (daum-title)]:
   - 3단 결합 공식(자극적 훅 + ... + 팩트/블라인드/감정종결어) 및 4대 템플릿(가성비 역전형, 상위 저격형, 충격 가격형, 경쟁 비교형) 기반 추천 10선과 추천 1위 메인 제목 도출
   - 🚨 CRITICAL HARD STOP: 제목 10선 보고 후 즉시 멈추고, 사용자님의 제목 선택 및 승인 대기
3. [2단계: 연쇄 본문 마스터 스킬 발동 (daum-article)]:
   - 사용자님이 승인한 대표 제목을 바탕으로 공백 포함 2,500~3,400자 분량의 다음.html 원고 빌드
