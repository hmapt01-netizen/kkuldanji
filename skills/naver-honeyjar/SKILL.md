# 🛑 2. 해요 / 하더라 말투 전면 금지 및 정통 전문 칼럼 문체 (Mandatory Tone & Voice)

네이버 블로그 검사기에서 "확신 없는 말투" 또는 "가벼운 일기형 글"로 감점되는 `해요`, `하더라`, `~인 것 같아요`를 전면 금지하고, 독자에게 깊은 신뢰감과 무게감을 주는 **정통 건강·영양 전문 저널리스트 칼럼 어조**로 100% 작성한다.

1. **[설명 / 원리 / 영양 분석 문장]** ➔ `~입니다`, `~습니다`, `~구조입니다`, `~작용합니다`, `~확인됩니다`, `~밝혀졌습니다`, `~나타났습니다`
2. **[화두 / 독자 공감 / 질문 문장]** ➔ `~일까요?`, `~않을까요?`, `~대목입니다`, `~이유입니다`, `~배경입니다`
3. 🚨 **[절대 금지 문체]**: `~해요`, `~이에요`, `~느껴져요`, `~살펴볼게요`, `~하더라구요`는 단 한 문장도 쓰지 않는다.

# 📋 4. 네이버 블로그 6대 실전 정밀 서식 규격

### 1. `┌ ... ┘` 상단 꺾쇠 훅 박스 (hook-box)
* 원고 최상단(H1 제목 바로 아래)에 글 전체의 핵심을 찌르는 훅 문구를 중앙 정렬된 꺾쇠 박스로 배치한다.
```html
<div class="hook-box" style="background:#f8fafc; border:1px solid #e2e8f0; border-radius:12px; padding:20px; text-align:center; margin:20px 0; font-size:1.05rem; font-weight:bold; color:#0f172a; line-height:1.7;">
    ┌ 매일 무심코 비우던 식판 위의 탄수화물, 숟가락을 들기 전 딱 세 가지만 바꾸면 급격한 나른함 대신 온종일 맑은 활력이 지속됩니다. ┘
</div>
```

### 2. 소제목 번호 금지 및 서술형/질문형 H2 소제목
* `1.`, `2.`, `Step 1` 등의 번호를 소제목에 일체 붙이지 않는다.
* 독자의 궁금증을 자극하거나 핵심 기전을 설명하는 20자 내외 서술형/질문형 어미(`~원리`, `~배경은`, `~선택 기준`, `~차이점`)로 작성한다.

### 3. 정밀 비교표 2~3개 필수 수칙 (인라인 테두리 & 배경 스타일)
* 네이버 스마트에디터에서 깨지지 않도록 표 테두리(`border:1px solid #cbd5e1`), 헤더 배경(`#f1f5f9`), 셀 패딩(`padding:11px 13px`)을 인라인 스타일로 100% 명시한다.

### 4. 각 표 직하단 출처 상자 (source-box) 명시
* 표 바로 아래에 공인 보건/영양 연구 기관(질병관리청, 농촌진흥청, 하버드 보건대학원, 식품의약품안전처 등)의 공식 출처를 명확히 기록한다.
```html
<div class="source-box" style="font-size:0.85rem; color:#64748b; margin-top:6px; margin-bottom:24px; text-align:right;">
    출처: 국립농업과학원 농식품올바로 곡류 영양성분 데이터베이스 기준
</div>
```

### 5. 5장의 이미지 배치 및 쉼표 캡션 서식
* 본문 흐름에 맞춰 5장의 고유 사진을 고르게 배치하며, 캡션은 사진 속 원리를 짚어주는 담백한 1줄 설명으로 작성한다.
* 서식: `<p style="text-align:center; font-size:0.88rem; color:#64748b; margin-top:8px;">[사진 속 원리/상황 설명] / 사진=[제조사 또는 공식 원천]</p>`

### 6. [오늘 배운 3줄 핵심 요약] 포인트 박스 & 외부 링크 0개 유지
* 글 맨 하단에는 독자의 체류 시간을 극대화하고 만족도를 높이는 3줄 요약 박스를 배치한다.
* 🚨 **[애드센스 & 애드포스트 심사 기간 철칙]**: 본문 및 요약 박스 어디에도 외부 링크(URL)를 단 1개도 넣지 않는다. 오직 100% 자립형 완결 정보로만 작성한다.
