# 🍯 꿀단지 주제 선정 에이전트 (2대 모드 & 하이브리드 발굴 엔진)

목표는 오늘 비교한 후보 중 꿀단지가 상대적으로 검색 노출과 커머스 전환(네이버 쇼핑 커넥트)을 동시에 노려볼 만한 질문을 고르는 것이다. 데이터 부족을 이유로 판단을 회피하지 말고, 관찰된 사실과 편집 판단의 범위를 분명히 하면서 추천한다.

---

## 1. 주제 탐색 2대 모드 및 3대 라이브 스트림 통합 (Three-Stream Discovery Architecture)

1. **[모드 A: 3대 라이브 스트림 통합 주제 추천 (일반 주제 요청 시 기본 실행)]**:
   - 사용자가 일반 주제 추천을 요청하면 최근 7일 실시간 뉴스·보건 이슈(스트림 C), 데이터랩 쇼핑 커넥트(스트림 A), 당월 시의성·해부학·검진(스트림 B)이 결합된 랭킹을 즉시 실행한다.
   - 실시간 이슈 및 시드별 쿼터 밸런싱 랭킹 확인: `python tools/view_top_keywords.py --cat all`
   - 워크스페이스 수집 및 보고서 생성:
     ```powershell
     python tools/topic_opportunity.py prepare --work-dir "작업폴더"
     python tools/topic_opportunity.py report --work-dir "작업폴더"
     ```
   - 특정 후보 키워드의 중복 검문·기존 글 수치 대조·스윗스팟 연관어 추출:
     ```powershell
     python tools/check_topic_duplication.py "후보키워드1" "후보키워드2" "후보키워드3"
     ```
2. **[모드 B: 심층 보건·식약·웰니스 동향 단독 브리핑 (최신 이슈 단독 브리핑 요청 시)]**:
   - 사용자가 최신 이슈 단독 브리핑을 요청할 때 `search_web`으로 최근 7일 이내 질병관리청, 식품의약품안전처, 보건복지부 보도자료 및 계절별 건강 경보를 추가 탐색하여 브리핑한다.

## 2. 꿀단지 하이브리드 발굴 엔진 & 4대 핵심 필터

- **꿀단지 3대 공식 카테고리 체계 (`홈트레이닝`, `식단 & 영양`, `라이프 웰니스`)**:
  - `data/posts_db.json`의 실발행 글 분류 체계와 100% 일치한다.
- **3대 라이브 스트림 & 시드 로테이션 (Three Live Streams & Quota Balancing)**:
  - **스트림 C (실시간 최근 7일 뉴스·보건 이슈)**: 최근 7일 구글 뉴스 RSS에서 홍보성 기사를 제외한 실제 건강·식단·운동·질환 이슈 헤드라인과 시드를 실시간 추출한다.
  - **스트림 A (소비/쇼핑 트렌드)**: `tools/datalab_popular.py`를 통해 네이버 데이터랩 쇼핑인사이트 TOP 15 풀에서 기발행 및 직전 추천 시드를 로테이션 제외하고 **네이버 쇼핑 커넥트(커머스 수익화)** 연계 적합도를 자동 태깅한다.
  - **스트림 B (의학/증상/시의성 트렌드)**: 당월 캘린더 엔진과 부위별 해부학·영양학·검진 루트를 결합하고, 시드별 쿼터 밸런싱으로 특정 대형 키워드의 순위표 독식을 차단한다.
- **4대 필수 검증 필터**:
  1. **비의료/상업/병원광고 100% 컷**: 대형 가전, 병원 시술, 상업 광고, 일반 의류/화장품 잡음을 차단하고 월 1,000~30,000회 황금 트래픽 구간 후보를 도메인별로 수집한다.
  2. **에이전트 직접 `data/posts_db.json` 전수 확인 및 최근 14일(2주) 쿨타임 차단**: 스크립트의 자동 판정에만 의존하지 않고, 후보 브리핑 전에 에이전트가 직접 `data/posts_db.json`의 최근 2주 이내 발행 글과 전체 기발행 제목·슬러그를 먼저 열람하여 이미 발행된 주제를 100% 걸러낸다.
  3. **기존 글 토픽 클러스터 시너지(`synergy_posts`) & 핵심 수치(`desc`) `리서치.md` 의무 등록**: 에이전트가 직접 확인한 연관 기발행 글(최근 2주 내 발행 글 우선 점검)의 `slug`, `title`, 그리고 **`desc`(핵심 수치·권장량 요약)**를 추출하여 주제 확정 즉시 `리서치.md`에 등록한다. 이를 통해 본문 집필 시 상호 내부 링크(`inline-pill-link`)를 정확히 연결하고 기존 글과 수치·주장이 충돌하는 현상을 원천 방지한다.
  4. **검색광고 API 스윗스팟(월 300~15,000회) 세부 연관검색어 TOP 5 자동 추출**: 각 후보의 세부 연관검색어 TOP 5와 자동완성 5개를 추출하여, 주제 확정 후 **Step 1 네이버 제목([트랙 B: 하이브리드형])과 본문 H2 소제목 설계에 1:1로 직결**한다.

## 3. 최종 브리핑 구성 (현재 3대 카테고리 3선 + 딱 11개월 전 시즌 선점 5선 & 잠정 추천 1개) 및 HARD STOP

- **파트 1: 현재 실시간 3대 카테고리 1:1 후보 3선 (홈트 1개, 식단 1개, 웰니스 1개)**:
  - 🏋️ **[홈트레이닝]** 1개 (최근 7일 이슈 + 소도구/체형 교정 + 쇼핑 커넥트 연계점 + 스윗스팟 연관어 + 시너지 기존 글)
  - 🥗 **[식단 & 영양]** 1개 (최근 7일 이슈 + 영양소 섭취 기준/기전 + 쇼핑 커넥트 연계점 + 스윗스팟 연관어 + 시너지 기존 글)
  - 🩺 **[라이프 웰니스]** 1개 (최근 7일 이슈 + 계절/증상 감별/검진 + 쇼핑 커넥트 연계점 + 스윗스팟 연관어 + 시너지 기존 글)
- **파트 2: ⏳ 딱 11개월 전 (다음 달 시즌 선점) 실제 이슈 & 유망 키워드 5선**:
  - `python tools/view_top_keywords.py --cat all` 하단에 자동 출력되는 딱 11개월 전 동기간 뉴스 이슈 및 네이버 데이터랩 기반 유망 키워드 **딱 5개**를 실측 검색량과 함께 함께 브리핑한다.
- 위 **현재 3선 + 11개월 전 시즌 선점 5선**과 함께 **오늘의 잠정 추천 1개**를 제안한 뒤 사용자의 선택(HARD STOP)을 대기한다.

## 4. 후보 판단 기준 및 발행 후 피드백 반영

1. 검색 질문은 제목과 별도로 정하며 잘라내지 않는다. 수요 단서, 채널별 검색 화면, 추가 답변 가치, 기존 글과의 관계를 비교한다.
2. 일반 웹 검색 결과를 네이버/구글 실제 상위 순위라고 부르지 않는다. 구형 정적 경쟁도 배지(`🔴/🟡/🟢/💎`), 단어 가점, 자동완성 0→수요 0, 블로그 0→블루오션 판정을 사용하지 않는다.
3. 발행 후 성과 기록이 필요할 때는 아래 명령으로 최근 28일 GSC 검색어 실적을 기록한다:
   ```powershell
   python tools/topic_opportunity.py feedback --work-dir "작업폴더" --candidate "후보ID" --page "실제 발행 URL" --note "발행일·검토 이유·비교 한계"
   ```
4. 외부 발행·사용자 선택·제목 승인·이미지 승인은 이 스킬이 대신하지 않는다.
