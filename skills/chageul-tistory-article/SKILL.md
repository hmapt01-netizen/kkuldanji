# 🏛️ 티스토리(Tistory) '차를 쓰다' 블로그 100% 맞춤 글쓰기 스킬 (`tistory-article`)

🚨 **[최우선 필수 이행 수칙]**: AI는 절대 자신의 과거 대화 기억이나 짐작, 추측으로 글을 작성하지 않으며, 이 스킬 문서의 모든 세부 규칙과 지침 전체를 눈으로 직접 확인하고 정독한 뒤에만 원고 작성에 엄격히 착수한다.

이 스킬은 실제 운영 중인 **'차를 쓰다' 티스토리 블로그(`chageul.com`)의 실전 HTML 아키텍처**와 **구글 SEO 및 사람 독자 체류 시간을 극대화하는 인간적인 글쓰기 지침**을 100% 반영하여 `티스토리.html` 원고를 작성하는 본문 전용 스킬입니다.

# 🛑 '차를 쓰다' 티스토리 100% 필수 HTML 구조 8대 원칙 (Mandatory Architecture)

### 1. 최상단 확장 Google JSON-LD Article 스키마 마크업 (★ 구글 SEO 1위 수칙)
* 코드 최상단에 `author`, `datePublished`, `dateModified`, `image`, `url`, `inLanguage`, `keywords`가 모두 포함된 확장 JSON-LD 스키마 필수 수록.
* `@id`와 `url`은 하드코딩된 특정 하위 주소 대신 **기본 대표 도메인(`https://chageul.com/`)**으로 깔끔하게 설정하여 발행 시 404 오차를 방지한다.
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "https://chageul.com/"
  },
  "url": "https://chageul.com/",
  "headline": "[메인 제목]",
  "description": "[메타 요약 설명]",
  "image": [
    "https://chageul.com/이미지/티스토리/t_01_ev6_charging.jpg"
  ],
  "inLanguage": "ko-KR",
  "datePublished": "2026-08-03T14:50:00+09:00",
  "dateModified": "2026-08-03T14:50:00+09:00",
  "author": {
    "@type": "Person",
    "name": "차를 쓰다"
  },
  "publisher": {
    "@type": "Organization",
    "name": "차를 쓰다"
  },
  "keywords": "중고전기차, 아이오닉5중고, EV6중고, 싼타페유지비, 차를쓰다"
}
</script>
```

### 2. 상단 4px 검정 테두리 훅 인용 박스 (`border-left: 4px solid #111;`)
* 스키마 바로 아래에 검정 4px 좌측 테두리가 들어간 훅 인용 박스 필수 수록.

### 3. 클릭 시 이동하는 목차 박스 (Table of Contents with `#section` Anchor Links)
* 도입부 아래에 섹션 1~5로 바로 순간 이동하는 클릭형 목차 박스 필수 수록.

### 4. `id="sectionN"` 전용 `<h3>` 소제목 태그 (Tistory `data-ke-size="size23"`)
* 모든 소제목은 번호 없이 `id="section1"`, `id="section2"` 앵커와 `border-left: 6px solid #666;` 테두리가 들어간 `<h3>` 태그로 작성.

### 5. 사람다운 리듬과 과장어 차단 수칙 (Humanized Writing Protocol)
* **결론 직격 도입부**: 서두에서 소설이나 서정적 현상 설명 금지. 첫 2문장 내에 핵심 결론을 바로 제시.
* **초반 수치 빽빽함 금지**: 첫 500자 안에 숫자를 3개 이상 몰아넣지 않는다.
* **전제조건 명시**: "기름값 1,400만 원 절감" 표현 시 반드시 (연 2만km, 휘발유 1,700원 vs 심야 완속 200원 기준) 전제조건을 서두와 표에 명시.
* **과장 및 금지 표현 철저 차단 (전면 금지 단어: `셈법`)**: `완파`, `폭증`, `압도적`, `신차급`, `파격`, `셈법`, `~를 자랑합니다`, `~를 선사합니다`, `~인기를 견인했습니다` 같은 부자연스럽거나 보도자료/광고성 어투 남용 차단 ➔ `뚜렷한 증가`, `큰 폭의 차이`, `실질적인`, `유의미한 절감`, `가성비가 우수한`, `~로 풀이됩니다`, `~라는 점이 실질적 차이로 체감됩니다` 사용.

* **팩트 안전성 준수**: SOH 수치는 "대부분 92~95%" 같은 단정 표현 금지 ➔ "SOH 90% 이상을 안정적으로 유지하는 사례가 다수 확인됨" 사용.
* **차종별 고유 이슈/약점 기반 정밀 분석 수칙 (상투적 의심 템플릿 금지)**: `"처음엔 굼뜨거나 답답할까 봐 걱정했는데..."` 식의 기계적 템플릿을 전면 금지하며, 반드시 `리서치.md`에 수집된 **해당 차종의 고유한 역사적 약점, 기술적 논란점, 차주들의 구체적 우려 팩트**(예: 기존 전륜 6단 하이브리드의 꿀렁거림, 3.5T 가솔린의 유류비 부담 등)를 핀포인트로 짚어 신기술 팩트와 주행 직결감으로 정교하게 풀어서 작성한다.
* **도입부 최신성 선언 & 핵심 변경점 3초 요약 수칙**: 도입부 서두 상단 200자 이내에 제목의 `[YYYY년형 신형 차명]` 최신성 키워드를 회수·선언하고, 3대 핵심 변경점을 3초 만에 파악 가능하게 요약 배치한다.
* **소제목 실익 중심 세분화 수칙**: 단순 명사 나열을 엄격히 금지하고, 독자가 얻을 실질적 이점/효용 2가지가 명시된 문장형 소제목(`[핵심 기능/기술]의 편리함 [이점/소음/승차감]으로 더욱 [조용해진/쾌적해진] [실내/하체/주행]`)으로 작성한다.
* **실생활 검색어 FAQ 5선**: `Q. 중고 전기차 사면 배터리 무상 보증 진짜 되나요?` 처럼 실제 사람이 검색창에 입력하는 질문으로 구성.
* **AI 기계적 문단 패턴 파괴**: 문단 사이에 대화형 브릿지 문장("그렇다면 실제 계산은 어떨까요?", "반대로 이런 운전자라면 추천하기 어렵습니다.")을 섞어 사람다운 글 리듬 생성.
* **동일 단어·일반 명사 글 전체 반복 제한 수칙**: 글 전체(2,500~3,500자 기준) 통틀어 일반 공통 명사(`자율주행`, `가격`, `기술` 등)의 총출현 횟수가 8회 이하를 넘지 않도록 제한하며(밀도 1.5~2% 유지), 문단 내 연속 중복 금지 및 일반 명사 유의어 변환을 이행한다. **(🚨 단, 고유 차명 및 브랜드명인 `테슬라`, `모델Y`, `BMW 5시리즈`, `BYD`, `그랜저` 등은 캡 적용 및 지시대명사 회피 대상에서 전면 제외하며, 본문 전체에서 답답함 없이 실명으로 시원하게 작성해야 한다.)**

# 📸 이미지 관리 & 프롬프트 파일 표준 규정

1. **주제별 전용 작업 폴더 및 파일 분리 수칙**:
   - 글 작성 시 현재 날짜와 주제 키워드로 **`YYYY-MM-DD-주제명`** 형태의 전용 작업 폴더를 자동 생성한다.
   - 원고 파일(`티스토리.html`), 이미지 프롬프트 가이드(`혀니결론 이미지 프롬프트.md`), 및 `이미지/` 폴더는 해당 전용 작업 폴더 경로 하위에 저장한다.
     - **티스토리 원고**: `YYYY-MM-DD-주제명/티스토리.html`
     - **이미지 프롬프트 가이드**: `YYYY-MM-DD-주제명/혀니결론 이미지 프롬프트.md`
     - **티스토리 이미지**: `YYYY-MM-DD-주제명/이미지/티스토리/`
2. **무조건 영문 파일명 & 플랫폼 접두사 규칙**:
   - 모든 이미지 파일명은 **무조건 영문(English)**으로 작성한다.
   - 티스토리 채널용: `t_` 접두사 + 영문 설명 (예: `t_01_ev6_charging.jpg`)
3. **혀니 결론 썸네일/이미지 프롬프트 작성 지침 (★ 2줄 썸네일 한글 마스터 서식 수칙)**:
   - `혀니결론 이미지 프롬프트.md` 문서 작성 시, 반드시 아래 **한글 마스터 텍스트 서식**을 그대로 준수하여 작성한다:
     ```text
     # 🎨 혀니 결론 썸네일 AI 이미지 생성 프롬프트 가이드 (티스토리 전용)

     이 문서는 참고 이미지 2장(이미지 1: 캐릭터 / 이미지 2: 실물 차 사진)을 AI(ChatGPT, Midjourney 등)에 첨부하고 바로 실행하는 썸네일 프롬프트 가이드입니다.

     ## 🤖 마스터 AI 프롬프트
     AI 이미지 생성 창에 [이미지 1: 캐릭터]와 [이미지 2: 차량 사진] 2장을 함께 첨부(Upload)한 뒤 아래 텍스트를 그대로 복사해서 입력합니다.

     첨부한 캐릭터(이미지 1)가 첨부한 차량(이미지 2)을 손가락으로 가리키며 설명하는 16:9 유튜브 썸네일 스타일 이미지 생성해줘. 
     설명문구: "[1줄 수치/팩트 문구]", "[2줄 메인 제목/차명 공개 결론]"
     ```
   - 단, 결론 이미지이므로 제목용 정답 은닉 표현(`'이 SUV'`, `'이 차'` 등)만 **실제 차명(예: `신형 아반떼`, `신형 X5`, `쉐보레 트레일블레이저` 등)**으로 명확하게 공개·교체하여 2줄 설명문구를 작성한다.
   - 🚨 **[썸네일 문구 간결성 & 결론 수칙]**: 썸네일 텍스트 박스 특성상 서술형 문장이 길어지면 가독성이 크게 떨어지므로, **각 줄 15~20자 이내의 임팩트 있는 임팩트 헤드라인 문구**로 작성한다. 의문형(`?`) 대신 실제 차명이 포함된 명확하고 간결한 한 줄 결론(예: `셀토스 대신 쉐보레 트레일블레이저인 이유`, `테슬라 모델 Y 꺾고 선두 복귀한 신형 그랜저`)으로 정제하여 완성한다.
