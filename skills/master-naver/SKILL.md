# 🟢 네이버 블로그 마스터 글쓰기 스킬 (Master Naver Skill)

🚨 **[최우선 필수 이행 수칙 - HARD STOP 프로세스]**: 
사용자가 기사 내용이나 키워드를 제공했을 때 **절대 본문 파일부터 바로 작성하지 않는다.** 
반드시 **리서칭(검색량·연관어 분석)**을 거쳐 **[검색량 추천 5개 + 네이버 연관어 추천 5개 = 총 10개 제목]**을 먼저 제시하고, **사용자가 제목 번호와 글쓰기 유형(1. 정보형 / 2. 홈판형)을 선택할 때까지 대화를 즉시 중단(HARD STOP)**한다. 사용자 승인이 완료된 후에만 본문 작성을 진행한다.

---

# ⚡ 1. 3단계 연쇄 발동 & 승인 프로세스 (Mandatory Orchestration)

1. **[0단계: 기사 팩트체크 & `리서치.md` 파일 선행 작성 (필수)]**:
   - 사용자가 제공한 기사/주제를 바탕으로 웹 검색 및 네이버 연관어/검색 트렌드를 리서칭한다.
   - 대중의 검색 의도(이슈/화제성)와 네이버 검색 연관어 5~6개를 선별한다.
   - 🚨 **리서치 결과물 기록**: 조사한 핵심 팩트, 출처, 키워드 분석 내용을 해당 주제의 전용 작업 폴더에 **`리서치.md` 파일로 반드시 선행 생성/저장**한다.

2. **[1단계: 2개 그룹 제목 10선 제시 & HARD STOP]**:
   - 아래 2개 그룹으로 명확히 분류하여 제목 10선을 사용자에게 출력한다:
     - 🟢 **[검색량 추천 5개]**: 화제성, 대중 유입, 클릭률(CTR) 중심 제목 5종
     - 🟢 **[네이버 연관어 추천 5개]**: 네이버 연관 검색어, 롱테일 키워드 결합 제목 5종
   - 🚨 **[CRITICAL HARD STOP RULE]**: 제목 10선을 출력한 후 **"원하시는 제목 번호와 글쓰기 유형(1. 정보형 / 2. 홈판형)을 선택해 주세요"**라고 안내하고 즉시 대화를 멈춘다. 사용자 선택 전에는 절대 본문을 작성하지 않는다.

3. **[2단계: 사용자 승인 후 선택된 모드로 본문 작성]**:
   - 사용자가 선택한 유형([정보형] 또는 [홈판형])의 정밀 규격에 맞춰 스마트에디터 ONE 서식과 금칙어 100% 차단이 적용된 최종 원고를 생성한다.

# 🎨 2. 제목 구성 포뮬러 (검색량 추천 5종 + 네이버 연관어 5종)

### 📌 그룹 A: [검색량 추천 5개] (화제성 & 대중 유입)
1. **[추천/표준 정석형]**: `[핵심 이슈 키워드] + [구체적 팩트] + [공식 입장/결과]`
2. **[호기심·의문형]**: `[독자 궁금증 유발] + [논란/사건의 핵심] + [현재 상황]`
3. **[숫자·타임라인형]**: `[구체적 수치/시점/세대] + [핵심 쟁점 요약]`
4. **[문제-해결/여파형]**: `[사건 발생] + [방송/브랜드/주변 여파 및 대응]`
5. **[공식 팩트체크형]**: `[인물/사건] + [전문기관/당사자 공식 입장 및 전말]`

### 📌 그룹 B: [네이버 연관어 추천 5개] (세부 연관어 & 롱테일)
1. **[인물-배경 연관형]**: `[메인 인물] + [집안/가족/출신 연관어] + [핵심 내용]`
2. **[프로그램/브랜드 연관형]**: `[인물] + [출연작/광고/브랜드 연관어] + [현황 및 이슈]`
3. **[법적/역사적 연관형]**: `[사건 키워드] + [기관/법적 쟁점 연관어] + [상세 분석]`
4. **[과거-현재 연관형]**: `[과거 발언/행적] + [현재 논란/입장 연관어] + [총정리]`
5. **[대중 반응 연관형]**: `[네티즌 반응/실시간 이슈] + [향후 전망/행보]`

# 📝 3. 2대 글쓰기 유형별 정밀 본문 지침 (Dual Writing Modes)

### 🔍 모드 1: [정보형 지침] (네이버 통합검색 / 스마트블록 / SEO 1위 장악용)
* **타겟 알고리즘**: C-Rank & DIA+ 검색 알고리즘 (키워드 매칭 및 정보 만족도)
* **말투/톤**: 격식체(~습니다) 일관
* **도입부 (직답형)**: 공백 포함 80~120자, 2~3문장 안에 검색자가 원하는 결론과 핵심 근거(대상/조건/상태)를 바로 제시.
* **소제목 구조 (정확히 H2 6개 + FAQ H2 1개)**:
  - **H2 정확히 6개** 구성: 6개의 H2마다 리서치된 **네이버 연관 검색어를 1:1로 자연스럽게 필수 포함**.
  - **문단 및 문장 규격**: 각 소제목당 **정확히 3개 문단**, 각 문단당 **정확히 3개 문장**으로 구성 (총 약 2,000자).
  - **문단 서술**: 기호(`-`, `*`, `·`)나 번호 매기기 없이 **완결된 줄글 문장**으로 작성 (항목 나열 시 쉼표 사용).
* **하단 FAQ (5쌍 필수)**: 본문 맨 하단에 실제 검색자가 검색창에 입력할 법한 자연스러운 Q&A 5쌍 배치.
* **마무리**: 단순 요약이 아닌, 독자가 지금 확인할 공식 정보와 다음 행동을 1문단으로 명확히 제시.

---

### 🔥 모드 2: [홈판형 지침] (네이버 MY피드 / 홈판 / 디스커버 / 스토리텔링용)
* **타겟 알고리즘**: AiRS 추천 알고리즘 (클릭률 CTR, 완독률, 체류 시간 극대화)
* **말투/톤**: 몰입감 있고 담백한 격식체(~습니다)
* **도입부 (맥락/후킹형)**: 첫 2문장에 사건의 주체, 확인된 핵심 팩트, 독자에게 중요한 이유를 흥미롭게 제시.
* **소제목 구조 (정확히 H2 4개 - 기승전결 서사)**:
  - **H2 정확히 4개** 구성: 기계적 키워드 반복 금지, 드라마틱한 서사 흐름으로 구성.
  - **전개 순서**: 
    `1. 사실과 출처 맥락` ➔ `2. 사건의 발단 및 핵심 쟁점` ➔ `3. 당사자·관계자 공식 입장 및 발언` ➔ `4. 파장, 영향 및 현재 상황`
  - **문단 및 문장 규격**: 각 소제목당 **정확히 3개 문단**, 각 문단당 **정확히 4개 문장**으로 작성 (총 약 1,800자).
  - **문단 서술**: 한 문장을 잘게 쪼개지 않고, 긴 호흡으로 읽히는 **완결된 스토리텔링 줄글 문단** 구성.
* **키워드 전략**: 메인 키워드 1개만 자연스럽게 사용 (H2마다 키워드 억지 반복 배제).
* **금지 사항**: 과장 어그로("충격", "난리", "역대급", "완벽") 및 구독/좋아요 요청 배제.

# 🔗 4. 서사 직결 원칙 (제목 ➔ 첫 문단 ➔ 소제목)

네이버 검색 엔진의 **주제 일관성(Relevance)**을 극대화하기 위해, 선택된 제목의 핵심 키워드가 본문 첫 줄에서 즉각 반응해야 한다:

* **[선택된 제목 예시]**: `하영, 증조부 친일 행적 논란 속 자필 사과문 발표`
* **[첫 문단 시작 문장]**: 
  `"배우 하영이 최근 불거진 증조부의 친일 행적 논란과 관련해 직접 자필 사과문을 공개하며 입장을 밝혔습니다."`
* ➔ **효과**: 유입 독자의 이탈을 방지하고 체류 시간을 늘려 DIA+ 랭킹 점수 획득.

---

# 🛑 5. 네이버 C-Rank & DIA+ 금칙어 100% 차단 수칙

네이버 검색 봇의 상업성/홍보성/자극성 감점 필터를 완벽히 우회하기 위해 아래 단어를 100% 대체한다:

1. `최고` ➔ `상당한`, `우수한`, `뛰어난`
2. `추천` ➔ `권장`, `참고할 만한`, `눈여겨볼 만한`, `대안`
3. `후회` ➔ `아쉬움`, `착오`
4. `가장` / `1위` ➔ `상당히`, `대표적인`, `손꼽히는`
5. `구매` / `판매` / `가격` ➔ `마련`, `선택` / `공급` / `금액대`, `수치`
6. `블로그` / `사이트` ➔ `공간`, `채널`, `공식 기록`
7. `만족` / `확실` ➔ `실속`, `효용` / `뚜렷한`, `명확한`
8. `진단` / `100%` ➔ `점검`, `확인` / `충분히`, `고스란히`
9. `서술했다` / `밝혔다` ➔ `전해졌어요`, `공개되었어요`, `알려졌습니다`

# 🎨 6. 스마트에디터 ONE 본문 서식 가이드

* **소제목**: `[인용구: 버티컬라인]` 표기 (네이버 초록색 바)
* **안내/콜아웃 박스**: `[인용구: 박스]` 표기
* **사진 캡션**: 과장 없는 담백한 사실 기술 (`배우 하영 공식 입장문 관련 / 출처: 공식 SNS`)
* **이모지 전면 배제**: `01`, `02` 등 숫자 배지 및 기호 사용
* **네이버 해시태그**: 본문 맨 하단에 10개 내외 태그 제공 (`#하영 #하영사과문 #하영친일논란 ...`)

# 📸 7. 고화질 이미지 생성 및 네이버 SEO 배치 가이드

* **적정 장수 및 폴더 구조**:
  - 본문 2,000자 기준 **4~6장** (대표 썸네일 1장 + 소제목 섹션별 3~5장).
  - 생성된 이미지는 해당 작업 폴더 내 `이미지/` 하위 디렉토리에 체계적으로 저장한다.
* **파일명 SEO 최적화 규칙 (필수)**:
  - `image1.jpg`, `KakaoTalk_01.jpg` 같은 무의미한 파일명 절대 금지.
  - 반드시 핵심 검색 키워드를 포함하여 명명한다: `[메인키워드]_[세부식재료_또는_주제].jpg` (예: `8월_제철음식_전복.jpg`, `늦여름_보양식_장어.jpg`).
  - ➔ **효과**: 네이버 이미지 검색 탭 및 스마트블록 이미지 컬렉션 상위 노출 획득.
* **이미지 캡션 및 비율 표준**:
  - **화면 비율**: 모바일 가독성에 최적화된 **4:3** 또는 **3:2** 가로 비율 적용.
  - **담백한 캡션**: 과장 없는 사실 그대로 명시 (`8월 제철 수산물 전복 요리 모습 / 사진: 자체 제공`).
