# 1/32 수분 섭취 글 로컬 수정

기존 제목: 체중별 하루 적정 수분 섭취량과 올바른 물 마시는 시간대

수정 제목: 하루 물 섭취량, 체중만으로 정해도 될까? 커피와 식사 중 물 마시는 습관

| 기존 문제 | 수정 방향 |
|---|---|
| 체중 계산식으로 정확한 개인별 양 제시 | 음식·음료·활동·날씨·질환에 따라 달라짐을 설명 |
| 커피가 마신 양의 1.5~2배 수분을 배출 | 평상시 커피도 수분 섭취에 포함, 고정 보충량 제거 |
| 식사 중 물 100mL 제한 및 식후 1시간 대기 | 소화액 희석을 이유로 일률적으로 제한하지 않음 |
| 세포 흡수율 200%, 취침 전 물의 심뇌혈관질환 예방 | 근거가 확인되지 않은 효능 약속 제거 |
| 소변 색으로 상태 확정 | 색은 참고 지표이며 다른 증상과 함께 고려 |
| 포괄적인 학회명 출처가 실제 링크보다 우선 표시됨 | 확인한 NHS·Mayo Clinic·NIDDK 자료 5개로 연결 |

독자에게 추가한 것: 텀블러에 채운 양과 남긴 양을 구분하는 계산 예시. 권장량이나 실제 체험담이 아닌 가상 계산으로 명시.

## 검수

- DB에서 실제 변경된 글은 1개, 나머지 31개 원고 동일.
- 제목/H1/검색 설명/Article 구조화 데이터 및 FAQ 본문/FAQPage 데이터 일치 확인.
- 기존 썸네일과 본문 사진 4개, 발행일, URL, 편집자 추천 상태 유지.
- 사이트 빌드 및 로컬 검사 통과: HTML 43개, 내부 링크 1,161개, 에셋 참조 771개, 오류 0건.
- 브라우저에서 PC 제목·본문·표 확인, 모바일 390px 화면에서 사진·문단·표 확인. 표는 내부 가로 스크롤이며 문서 전체 가로 넘침 없음.
